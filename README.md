# R-NOT

Библиотека для генерации латентных представлений (единичных векторов) на гиперсфере ровно за **два вызова нейросети**.

* Шаг 1 — грубый прыжок по дуге большого круга из точки шума.
* Шаг 2 — точная доводка до результата.
* Какой шум в какой пример переводить при обучении, решает полудискретный оптимальный транспорт (сбалансированные ячейки Лагерра).

## Установка

```bash
pip install git+https://github.com/Burstgalaxy/rnot
```

## Попробовать в браузере

Сайт с генератором цифр: https://Burstgalaxy.github.io/rnot/ — нейросеть считается прямо на вашем устройстве, без сервера.

## Пример

```python
import torch
from rnot import RNOT

codes = torch.nn.functional.normalize(torch.randn(3000, 64), dim=-1)   # ваши латентные коды
labels = torch.randint(0, 10, (3000,))                                 # их классы

gen = RNOT(dim=64, num_classes=10).cuda()
gen.fit(codes, labels, seconds=300)        # обучение по времени
z = gen.sample(torch.tensor([3, 3, 7]))    # 3 новых кода за 2 вызова сети
gen.save('rnot.pt')
gen.export_onnx('rnot.onnx')               # для запуска в браузере (onnxruntime-web)
```

Хороший режим работы — ученик: обучите R-NOT на готовых результатах медленного генератора (учителя),
и он будет выдавать похожие результаты за 2 шага. Внутренности учителя (шум, путь, веса) не нужны.

Пример полного цикла на рукописных цифрах — `examples/mnist_demo.py`.
