Генератор цифр R-NOT

Нейросеть рисует рукописные цифры за 2 вызова вместо 128. Всё считается прямо на этом устройстве, без сервера.

Загружаю нейросеть…

Как это работает

Шум на сфере

Берётся случайная точка на поверхности многомерной сферы.

Два прыжка по дугам

Первый прыжок грубый, второй точный. Куда прыгать, сеть выучила по правилам оптимального транспорта.

Картинка

Декодер превращает точку сферы в картинку 28×28 пикселей.

Проект Андрея Пимшина, 10 «Т» класс. Метод R-NOT: Риманов оптимальный транспорт на гиперсфере. Нейросеть обучена на наборе MNIST.
